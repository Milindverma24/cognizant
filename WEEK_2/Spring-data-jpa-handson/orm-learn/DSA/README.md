# Data Structures and Algorithms (DSA) Exercises

A collection of basic Java programs exploring standard data structures, search algorithms, array indexing, and sorting techniques.

---

## 🎯 Objective
- Practice basic Java control structures (loops, scanner input, print commands).
- Implement standard array search and sorting techniques:
  - **Bubble Sort:** Swapping adjacent elements in `O(N^2)` time complexity.
  - **Selection Sort:** Selecting minimum element index in `O(N^2)` time complexity.
  - **Linear Search:** Searching arrays sequentially in `O(N)` time complexity.
- Implement mathematical conversions (Decimal to Binary).

---

## 📂 File Directory Structure

### 1. Array Operations
- [arrayfisrt.java](src/Arrays/arrayfisrt.java) - Array initialization and display logic.
- [average.java](src/Arrays/average.java) - Computes mean value of double/integer array elements.
- [sum.java](src/Arrays/sum.java) - Sums element values in integer arrays.
- [smallest.java](src/Arrays/smallest.java) - Finds minimum value inside array indexes.
- [largestNoArray.java](src/Arrays/largestNoArray.java) - Finds maximum value inside array indexes.
- [EvenAndOddCount.java](src/Arrays/EvenAndOddCount.java) - Categorizes and counts even/odd occurrences.
- [LinearSearch.java](src/Arrays/LinearSearch.java) - Sequentially searches for matching array values.

### 2. Sorting Algorithms
- [bubbleSort.java](src/sorting/bubbleSort.java) - Sorts array inputs using Bubble Sort algorithms.
- [selectionSort.java](src/sorting/selectionSort.java) - Sorts array inputs using Selection Sort algorithms.

### 3. Utility Math Exercises
- [decimal_to_binary.java](src/decimal_to_binary.java) - Converts base-10 integer inputs to binary string outputs.
- [print.java](src/print.java) - Base printer helper.

---

## 🏃 Execution Details
To run any of the compiled exercises:
1. Navigate to the `src` directory:
   ```bash
   cd src
   ```
2. Compile the desired package files:
   ```bash
   javac sorting/bubbleSort.java
   ```
3. Execute the class containing the main method:
   ```bash
   java sorting.bubbleSort
   ```
